# One Line, No Deadline Met

A small Python program that writes a single-line excuse for a missed deadline to `/output/entry.txt`.

The line uses a race-condition metaphor: the deadline and the speaker both arrived, just never at the same time. It is 86 characters, well under the 200-character gate.
